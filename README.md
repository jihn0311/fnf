# NEON DUET / 네온 듀엣

브라우저에서 실행하는 4방향 리듬게임. 오리지널 신스 곡 3개와 사용자 제공 MP3 1개를 포함합니다. `index.html`을 더블클릭하면 실행됩니다. 설치나 빌드가 필요 없습니다.

## 플레이

- 방향키 또는 D / F / J / K. 아래 버튼은 멀티터치를 지원합니다.
- 화살표 머리가 판정선에 닿을 때 누릅니다. 롱노트는 꼬리까지 계속 누릅니다.
- ESC로 일시정지/재개. 창을 벗어나면 자동 일시정지합니다.
- 롱노트 도중 일시정지한 경우 재개 후 0.25초 안에 같은 키를 다시 누를 수 있습니다.
- 곡이 끝나면 점수, 정확도, 최대 콤보, 판정 개수와 랭크를 표시합니다.

## 설정

시작 전이나 결과 화면에서 곡과 설정을 선택합니다. 곡을 바꾸면 이전 결과와 노트가 초기화됩니다. 플레이와 일시정지 중에는 설정을 잠급니다.

- EASY: 2박 간격 위주.
- NORMAL: 1박 간격 위주.
- HARD: 반 박자 간격 위주.
- 롱노트는 곡마다 BPM에 맞춰 두 마디 시작에 배치하고 3박 동안 유지합니다. 같은 레인의 롱노트 구간에는 다른 노트를 겹치지 않습니다.
- 업스크롤: 아래에서 위로, 위쪽 판정선. 다운스크롤: 위에서 아래로, 아래쪽 판정선.
- 노트 속도: 0.5×–2.5×. 이동 속도만 바꾸며 음악 속도와 판정 시간은 바꾸지 않습니다.

## 판정

공식 [Scoring.hx의 PBOT1](https://github.com/FunkinCrew/Funkin/blob/main/source/funkin/play/scoring/Scoring.hx#L145) 점수 공식과 경계값을 사용합니다. 화면에는 기존 4단계 이름을 유지합니다. 원본 sick은 PERFECT, 원본 bad/shit은 모두 BAD로 표시합니다.

| 표시 | 절대 오차 | 정확도 가중치 |
| --- | --- | --- |
| PERFECT | 0~45ms (45 포함) | 100% |
| GOOD | 45 초과~90ms (90 포함) | 75% |
| BAD | 90 초과~135ms (135 포함) | 40% |
| BAD | 135 초과~160ms (160 포함) | 10% |
| MISS | 160ms 초과로 놓침 또는 롱노트 중간 해제 | 0% |

5ms 미만은 500점. 나머지 성공 입력은 `trunc(500 × (1 - 1 / (1 + exp(-0.08 × (오차ms - 54.99)))) + 9)`점입니다. 예: 5ms 499점, 20ms 480점, 45ms 353점, 80ms 68점, 90ms 37점, 135ms와 160ms 9점. 점수 구간을 선형 보간하지 않습니다. MISS는 -100점이며 총점은 음수가 될 수 있습니다. 경계값 오차를 막기 위해 입력 오차를 소수점 여섯 자리 ms로 정규화합니다.

PERFECT는 노트 색상의 스플래시를 표시합니다. GOOD까지 콤보가 이어지며 BAD와 MISS는 콤보를 끊습니다. 롱노트는 머리의 오차와 점수를 저장하고 끝까지 유지하면 한 번 확정합니다. 꼬리 도착 55ms 전부터 해제를 허용하며 그보다 일찍 놓으면 MISS입니다. 롱노트 BAD 입력 시 콤보를 즉시 끊고 완료 시에도 BAD를 반영합니다. 판정 범위 밖의 빈 입력은 감점하지 않습니다.

정확도 가중치, 결과 랭크, 게이지 및 롱노트 규칙은 이 게임의 규칙입니다. FNF 전체 동작을 그대로 복제한 것은 아닙니다. 기본으로 켜져 있는 연습 모드에서는 체력 0이어도 계속합니다. 연습 모드를 끄면 체력 0에서 즉시 게임 오버가 됩니다.

## 구성과 검증

NOVA와 ECHO는 Canvas 캐릭터이고 Midnight Circuit은 Web Audio 합성음으로 생성합니다. FNF 에셋은 사용하지 않습니다. 네 번째 곡은 사용자가 제공한 MP3 원본을 재생합니다. 인터넷 없이도 동작하며 웹 폰트를 불러오지 못하면 기본 글꼴을 사용합니다.

`game.js`의 `createChart()`는 채보, `scheduleMusic()`은 음악, `character()`는 캐릭터를 담당합니다. 음악과 판정은 같은 AudioContext 시계를 사용합니다.

`node test-game.cjs`로 난이도별 밀도, 박자 정렬, 롱노트 중첩, 4단계 판정, 중복 입력, 롱노트 완료/해제, 여러 키 공유, 일시정지/재개 유예, 속도/방향별 도착 시간, 결과 처리를 검사합니다.

## 대결과 합주

왼쪽 NOVA는 자동 연주, 오른쪽 ECHO는 플레이어입니다. 중앙 스피커를 사이에 두고 각자의 4레인을 표시합니다. 하단에는 캐릭터 아이콘이 움직이는 체력바와 점수·정확도·콤보·MISS를 표시합니다. 성공/실패에 따라 체력이 변하며 상대의 자동 연주는 플레이어 점수나 체력에 영향을 주지 않습니다.

Midnight Circuit은 4초 도입 뒤 4초 단위로 `상대 → 플레이어 → 상대 → 플레이어 → 합주 → 상대 → 플레이어 → 합주 → 상대 → 플레이어 → 합주`로 진행합니다. 마지막 합주는 44~46초, 46~48초는 마무리입니다. 합주에서도 플레이어는 오른쪽 노트만 누릅니다.

각 노트와 같은 시각에 두 캐릭터의 신스 보이스가 재생됩니다. NOVA는 낮은 음역과 왼쪽 스테레오, ECHO는 한 옥타브 높은 음역과 오른쪽 스테레오입니다. 롱노트는 음도 길게 유지합니다. 사람 목소리나 외부 음원 대신 자체 합성음으로 구현했습니다.

캐릭터는 박자에 맞춰 대기 동작을 하고, 노트 방향에 따라 좌우 기울이기·아래 숙이기·위로 뻗기를 합니다. 노래할 때 입이 움직이며 MISS에는 움찔하는 동작과 색 변화가 있습니다.

### 실행

`index.html`을 더블클릭하거나 `play.cmd`를 실행하세요. 로컬 서버는 `http://127.0.0.1:5174/`입니다. 이전 임시 서버 5173은 추가된 음원 경로를 지원하지 않으므로 새 주소를 사용합니다.

더블클릭 실행에는 `assets/self-embodiment-inline.js`의 동일 MP3 Base64 데이터를 사용하고, 서버 실행에는 MP3 파일을 가져옵니다. 음원 준비 실패 시 오류 안내와 재시도 버튼을 제공합니다. 게임을 다른 폴더로 옮길 때 `assets`와 `imported-chart.js`도 함께 옮겨야 합니다.

### 분석 및 검사

`analysis/index.html`과 `analysis/analyze.js`는 Web Audio로 음원을 로컬 해독하고 3개 주파수 대역의 에너지 특징을 추출합니다. `analysis/analyze-data.py`, `analysis/refine-tempo.py`, `analysis/build-chart.py`는 NumPy로 주기 추정과 채보 생성을 수행합니다. 재분석은 서버 실행 후 `/analysis/`에서 시작할 수 있습니다. 최종 채보는 `imported-chart.js`에 저장되어 재생 중 분석할 필요가 없습니다.

`node test-imported.cjs`는 난이도별 채보, 롱노트 겹침, 파트/합주 경계, 동일 오디오 시계에서 예약 시작, 일시정지/재개, 완주, 재시작, 로딩 실패/재시도, 신스 곡 복귀를 검사합니다. 기존 곡 검사는 `node test-game.cjs`입니다.
## ESC 메뉴

플레이 중 ESC 또는 하단 일시정지 버튼을 누르면 음악과 노트를 멈추고 세 가지 선택지를 표시합니다.

- 계속하기: 같은 시점부터 이어서 플레이합니다. ESC를 다시 눌러도 됩니다.
- 처음부터 재시작: 현재 음악을 종료하고 같은 곡·난이도·설정으로 다시 시작합니다. 점수·콤보·체력·노트를 초기화합니다.
- 곡 멈추기: 음악을 종료하고 곡 선택으로 돌아갑니다. 진행 중 점수는 초기화되며 곡·난이도·속도 설정은 유지됩니다.

MP3와 신스 곡 모두 지원합니다. 재시작 시 이전 음원을 먼저 종료한 뒤 오디오를 재개하므로 소리가 겹치지 않습니다.

## 판정·속도·상단 체력바 업데이트

판정 창은 PERFECT ≤60ms, GOOD ≤110ms, BAD ≤180ms로 확장했습니다 (BAD 정확도 가중치: ≤150ms 40%, 나머지 10%).
점수 계산 곡선은 유지됩니다. 노트 속도 0.25~5배는 슬라이더/숫자로 플레이 중에도 조절합니다.
곡 속도 0.5~2배는 시작 전에 선택하며 반주·보컬·채보가 같은 배속으로 동작합니다. 음높이도 함께 변합니다.
판정 오차와 롱노트 해제 허용 범위는 배속과 무관한 실제 시간 기준입니다.
곡 정보에 원곡 BPM(1배속), 현재 BPM·배속과 예상 재생 시간을 표시합니다.
체력바와 점수는 게임 화면 상단에 있습니다. 브라우저 검증: node test-speed-ui.cjs.
