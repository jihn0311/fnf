# Galaxy moving charts
Original: https://github.com/Allen98637/GalaxyMod/tree/main/source/modcharts
Author: Allen98637 and GalaxyMod contributors. Apache-2.0; see LICENSE.
M_cona.hx, M_underworld.hx, M_cyber.hx are the original sources.
Run analysis/convert-galaxy-native.py to regenerate galaxy-native.js.
The JavaScript adapter changes rendering to Canvas, uses fixed song-time updates,
and represents native window changes inside the game canvas. Sustain paths are sampled.
Easy and low-spec charts retain fixed lanes.
